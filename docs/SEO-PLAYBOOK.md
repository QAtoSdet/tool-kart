# SEO playbook — the honest path to real traffic

## First, the truth about rankings

- **No one can guarantee a #1 ranking.** Anyone who promises it is lying. Google uses hundreds
  of constantly-changing signals and deliberately resists gaming.
- **Technical SEO (done — see below) does not make you rank by itself.** It makes you *eligible*
  to rank and removes anything that would hold you back.
- **Rankings are won off-page and over time:** useful content, other sites linking to you, real
  user behaviour, domain trust, and months of consistency.
- **The realistic win for a new site is long-tail, lower-competition queries**, especially
  India-specific ones — not broad terms like "image compressor" that established brands own.

## What's already done (technical foundation)

You don't need to touch any of this; it's built in:

- Unique title, meta description and canonical URL per page
- Open Graph + Twitter cards, with auto-generated social share images per tool
- Favicon + PWA manifest + theme colour
- Structured data: WebApplication, FAQPage, BreadcrumbList, WebSite, Organization
- Visible breadcrumbs on tool pages
- sitemap.xml + robots.txt (auto-updated when you add tools)
- Fast, statically-rendered, code-split pages (good Core Web Vitals)
- Mobile-friendly layout + mobile nav
- Internal links between tools ("Try another free tool")
- Original, India-relevant content + FAQs on each tool page

## What only you can do (this is where rankings are won)

### 1. Target the right queries (keyword strategy)
Go after specific, lower-competition, high-intent phrases — ideally India-specific. Examples:
- "compress image to 50 kb for ssc form" (not just "image compressor")
- "sq ft to gaj converter" / "bigha to square feet" (region-specific land units)
- "home loan emi calculator sbi 2026" style long-tail
- "cgpa to percentage calculator mumbai university"
Each of these is winnable in months; the broad head term is not.

### 2. Publish consistently (the weekly habit)
- Add ~one new tool page per week (reuses the existing shell — see Task 11 in ROADMAP.md).
- Prioritise tools with clear search demand and higher ad RPM (GST, SIP, income tax, PDF tools).
- Expand/improve existing pages that start ranking on page 2–3.

### 3. Get the site indexed and monitor it
- Submit sitemap.xml in Google Search Console (and Bing Webmaster Tools).
- Request indexing for new pages.
- Each week, open the Search Console "Performance" report:
  - Find queries where you rank in positions 11–30 (page 2–3).
  - Improve those exact pages (better title, more relevant content, answer the query directly).
  - This is the single highest-return SEO activity for a small site.

### 4. Earn backlinks (slow but decisive)
- Share genuinely useful tools in relevant communities (Reddit, forums, student/finance groups)
  without spamming.
- Answer questions on Quora/forums and link your tool where it truly helps.
- Reach out to small blogs in your niche; offer the tool as a free resource.
- Quality over quantity — a few relevant links beat many junk ones (junk links can hurt).

### 5. Give it time
- New domains take months to earn trust. Expect little traffic for the first 2–4 months even
  with everything right. Compounding kicks in later.

## A realistic timeline

| Period | What to expect |
| --- | --- |
| Month 0–1 | Build + launch. Pages get indexed. ~0 traffic. |
| Month 2–4 | First long-tail pages start ranking; a trickle of visitors. Apply to AdSense once there's some traffic. |
| Month 4–8 | If you kept publishing weekly, traffic grows; first ad earnings. |
| Month 8–12+ | Compounding traffic; ₹5,000–10,000/month is realistic *if the habit continued*. |

## What NOT to do (will waste money or hurt you)
- Don't buy backlinks or use "rank in 7 days" services — risks a Google penalty.
- Don't stuff keywords unnaturally — modern Google penalises it.
- Don't chase broad head terms first — you'll pour effort into queries you can't win yet.
- Don't expect the build alone to rank — the content/link habit is the actual job.

## Bottom line
The site is technically as strong as code can make it. From here, ranking is a function of
**useful content + links + time + consistency** — all off-page, all yours. Target winnable
long-tail queries, publish weekly, and let it compound.
